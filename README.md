# 12주 피트니스 루틴

> 웨이트, 유산소, 스트레칭을 한 화면에서 관리하는 모바일 최적화 운동 루틴 앱.

[![Live Demo](https://img.shields.io/badge/Live%20Demo-GitHub%20Pages-blue?logo=github)](https://frioct.github.io/fitness-routine/)

---

## 배경

헬스장에서 운동할 때마다 오늘 루틴이 뭐였는지 다시 열어보고,
유산소와 스트레칭까지 따로 확인하는 과정이 번거로웠습니다.
그래서 날짜만 열면 바로 그날 루틴이 나오고, 필요하면 다른 요일도 바로 넘겨볼 수 있는
간단한 운동 루틴 페이지를 만들었습니다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 오늘 루틴 자동 표시 | 현재 요일 기준으로 그날의 루틴을 바로 표시 |
| 요일 직접 선택 | 상단 주간 스트립에서 다른 요일 루틴도 즉시 확인 |
| 웨이트 세트 체크 | 운동별 세트 버튼을 눌러 진행 상태를 바로 표시 |
| 근육통 기반 유산소 조정 | 운동 전 체크에 따라 유산소 강도를 안내 |
| C25K 진행 통합 | 시작일 기준으로 C25K 주차와 Day를 계산 |
| 휴식일 회복 가이드 | 수/토/일 회복 활동과 스트레칭 안내 |
| 스트레칭 영상 링크 | 각 스트레칭에 바로 볼 수 있는 영상 링크 제공 |

## 루틴 구성

| 요일 | 구성 |
|------|------|
| 월 | 상체 A + 인터벌 |
| 화 | 하체 A + Zone 2 |
| 수 | 휴식 + 스트레칭 |
| 목 | 상체 B + 인터벌 |
| 금 | 하체 B + Zone 2 |
| 토 | 휴식 + 스트레칭 |
| 일 | 완전 휴식 |

### C25K 구성

- 월/목 인터벌 러닝 기준으로 동작합니다.
- `startDate`를 기준으로 현재 주차를 계산합니다.
- 인터벌 데이터는 `schedule.js`에서 관리합니다.

## 프로젝트 구조

```text
fitness-routine/
├── index.html     # 메인 웹앱
├── routine.js     # 앱에서 직접 로드하는 루틴 데이터
├── routine.json   # 원본 루틴 데이터
├── schedule.js    # C25K 인터벌 스케줄
└── README.md
```

---

## 데이터 수정

루틴 데이터 원본은 `routine.json`에 있습니다.
배포용 페이지는 `routine.js`를 직접 읽으므로, 데이터 수정 후에는 `routine.js`도 함께 갱신해야 합니다.

예시:

```json
"startDate": "2026-04-14"
```
